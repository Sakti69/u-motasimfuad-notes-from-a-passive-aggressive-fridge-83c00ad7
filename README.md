Entry for the [Notes From a Passive-Aggressive Fridge](https://make.fun/competitions/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) competition on [make.fun](https://make.fun).

`main.py` writes one funny passive-aggressive note from a smart fridge to its owner to `/output/entry.txt`:

> Fourteen openings, zero meals, one yogurt dead since Tuesday: at this point I am not a fridge, I am a very cold mirror.

Run it with `python3 main.py`. The note is a single line of 119 characters, inside the competition's 1–200 character gate.
